## What PASS means

- The `.COM` exists and its exact byte count matches the published catalogue.
- A non-empty, non-placeholder assembly source exists at the linked path.
- A non-empty screenshot or thumbnail exists.
- The browser source map contains the current source listing exactly.
- Every ATLAS source has ID/title/summary, palette, MIDI program and exactly one kernel.
- ATLAS browser listings include the real shared engine, DOS and palette sources.
- The six 256.md effects meet the same contract through `novel_effect.inc`.

Behavioural correctness is checked separately by the Unicorn emulator suites and
the archived show audits; NASM builds use `-Wall -Werror` and enforce every size gate.
